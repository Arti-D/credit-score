# credit-score

## Цель проекта
На основе датасета [Home Credit Default Risk](https://www.kaggle.com/competitions/home-credit-default-risk)
рассчитывать кредитный рейтинг клиента и принимать решение о выдаче кредита;

## Что уже сделано
первичное EDA

## Запуск проекта
1. Клонировать репозиторий 
2. Положить исходные данные ([Kaggle](https://www.kaggle.com/competitions/home-credit-default-risk)) в созданную в корне репозитория папку data/raw
3. Установить все необходимые зависимости `python -m pip install -r requirements.txt`
4. Запустить ноутбук `notebooks/01_data_intro.ipynb`
